## 自動化驗證

在工作區執行：

    .\.venv\Scripts\python.exe -m unittest discover -s pvpve_escape\tests -p "test_*.py" -v
    .\.venv\Scripts\python.exe -m compileall -q pvpve_escape
    git diff --check

測試應覆蓋：

- 固定地圖配置在多次 create_match 中相同、所有矩形在世界內，且已確認的 9 筆安全區紅框警示保持一致。
- 使用完整世界畫布執行地形渲染測試時，34 個矩形中心都能取到各自的牆色或草叢色；再於正式 1280×720 畫面切換左上與右下相機位置，確認視窗內牆/草叢中心能取到對應填色，且地形層在角色與技能效果之前繪製。
- WorldRect、圓形玩家/怪物和牆的正面/斜向碰撞；碰牆時停止或沿牆滑動。
- 直線、光束與飛行投射物在第一面牆前截斷，牆後目標不受同次技能影響。
- 破陣者主要/終極技能、DASH 的薄牆破壞資格，厚牆不可破壞，其他角色/配件不得破牆。
- 遠程破牆同次施放不能穿過剛移除的薄牆；DASH 只能破第一面薄牆並完成剩餘位移。
- 草叢不阻擋移動或投射物，具資格能力可移除草叢，破壞狀態持續到本場結束。
- viewer_id=0 時自身在草叢內可見；其他 viewer 看不到角色、編號、生命值、狀態與瞄準線；離開或破壞草叢後下一次繪製恢復。
- 草叢隱藏不改變既有目標、碰撞、傷害與怪物仇恨結果。
- 4.9 秒沒有恢復、5.0 秒開始恢復、1 秒恢復最大生命值 10%，並在受擊/攻擊時重置；護盾吸收算受擊，普通 DASH/SHIELD 不算攻擊。
- 同一幀的受擊先於恢復，滿血/死亡/重生不會溢血或沿用舊計時。
- 以 1280×720、6 名玩家、最多 12 隻怪物與固定地形的正常場景先預熱，再完成至少 600 個更新/繪製迴圈，平均幀率至少 55 FPS。

初始基線曾有一項需獨立記錄的狀況：未提交的 `config.py` 將 `GUI_OPACITY_PERCENT` 設為 50，而當時既有測試仍期待 78；同時工作樹已有自動瞄準／投射物／戰鬥變更。依使用者要求保留這些變更，地形無關的技能數值 fixture 明確使用空障礙物清單，避免把功能 004 的地圖規則混入既有單元測試；不覆蓋或重置任何使用者修改。

## 啟動遊戲

    .\.venv\Scripts\python.exe -m pvpve_escape

預期開啟既有 1280×720 Pygame 視窗，啟動方式不變。

## 操作對照

- WASD：移動；滑鼠：瞄準。
- 左鍵：普攻；右鍵：大招；Space：配件。
- 選角畫面使用 1～6 選角色、Q/W/E 選配件、Enter 開始。
- R：回到選角並重新建立整場比賽；Esc：離開。
- F1：開發者模式；1～5 選假玩家；M 將選定假玩家放入撤離區；N 放回出生點。

## 手動驗收情境

### 1. 地圖與牆體

1. 啟動遊戲並開始任一角色。
2. 觀察地面、厚牆、薄牆與草叢；確認目前攝影機範圍內的地圖物件確實出現，牆體顏色和地圖不同，厚牆/薄牆彼此也能區分，薄牆有裂紋或斷線提示。
3. 以 WASD 探索地圖不同區域，確認固定配置中的 18 個牆體與 16 個草叢都會在攝影機移入座標範圍時出現在畫面中。
4. 以 WASD 從正面和斜向貼近牆，確認角色不會穿過；沿牆按斜向移動時可停止或滑動。
5. 在開發者模式觀察怪物接近牆，確認怪物同樣停在牆前而不穿牆。

### 2. 直線/飛行技能阻擋

1. 以狙擊者或其他有直線/飛行效果的角色，讓牆前與牆後各有一個可命中目標。
2. 朝牆後目標施放，確認投射物/光束停在牆前，牆後生命值與控制狀態不變。
3. 讓投射物從沒有牆的方向通過，確認既有命中結果仍正常。
4. 重複至少 20 次，確認高速投射物沒有偶發穿牆。

### 3. 破陣者與 DASH

1. 選擇破陣者，使用主要技能或終極技能對薄牆施放；確認薄牆消失，但遠程效果不穿過缺口影響牆後目標。
2. 使用 DASH 對薄牆衝刺；確認薄牆消失且衝刺完成牆前剩餘位移。
3. 讓 DASH 路徑再遇到第二面牆；確認第二面牆仍阻擋。對厚牆測試時確認厚牆永遠存在。
4. 分別使用其他角色與其他配件測試薄牆/厚牆，確認不能破牆。
5. 以破陣者能力或 DASH 經過草叢，確認草叢消失；普通移動和一般技能經過草叢不會被阻擋。

### 4. 草叢觀看者規則

1. 將人類玩家移入有效草叢，確認自己的角色、編號、生命值與狀態仍可看見。
2. 使用新增的 viewer_id 渲染測試，以非該玩家的視角繪製同一場；確認看不到草叢內玩家的角色、編號、生命值、狀態與瞄準線，但仍看得到草叢。
3. 讓玩家離開草叢，或用破壞能力移除草叢；確認其他視角在下一次繪製看見玩家。
4. 對草叢內已知位置的目標施放既有攻擊，確認傷害與目標規則不因隱藏改變。

### 5. 戰鬥外生命恢復

1. 讓玩家受到怪物或其他攻擊而變成非滿血，離開攻擊範圍。
2. 連續 4.9 秒不攻擊、不受擊，確認生命值不增加；到達 5.0 秒後確認恢復開始。
3. 再經過 1 秒，確認生命值增加最大生命值的 10%，且最後不超過最大值。
4. 在等待或恢復期間分別受到普通傷害、護盾吸收命中、施放主要攻擊/傷害或控場大招，確認各自重新等待 5 秒。
5. 在相同條件下只使用普通 DASH 或 SHIELD，確認動作本身不會阻止恢復。
6. 讓玩家死亡並等待重生，確認死亡期間不恢復、重生滿血且不沿用舊計時。

### 6. 新局重置與既有回歸

1. 破壞至少一面薄牆與一片草叢，按 R 重新開始。
2. 確認新場的所有牆與草叢恢復初始位置、類型與有效狀態。
3. 再確認原有角色選擇、技能、怪物、彈藥、死亡、撤離與勝負流程仍可操作。
4. 目前完整測試應為 159/159 通過；若後續其他工作樹出現 GUI 或既有功能基線差異，將其獨立記錄，不覆蓋未提交的使用者變更。
