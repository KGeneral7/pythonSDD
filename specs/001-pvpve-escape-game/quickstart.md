# 快速開始與驗證指南：PvPvE 中央撤離競技遊戲

> 本文件保留初始 PvPvE 功能在 v0.1.0 階段的驗證紀錄；目前整體回歸數據以最新功能的 quickstart 與驗收文件為準。

## 前置條件

- Windows PowerShell。
- Python 3.11 或更新版本；目前專案虛擬環境位於 `.venv`。
- 專案虛擬環境安裝 Pygame；不得依賴全域安裝。
- 執行位置為專案根目錄：`C:\Users\Yun-Tse Kao\Desktop\pythonSDD`。

## 安裝依賴

在專案根目錄執行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r pvpve_escape\requirements.txt
```

預期結果：Pygame 安裝於目前專案的 `.venv`，不修改全域 Python 環境。

## 執行遊戲

```powershell
.\.venv\Scripts\python.exe -m pvpve_escape
```

預期結果：

1. 顯示角色與戰術配件選擇畫面。
2. 選擇角色與配件後進入 6 人測試比賽。
3. 畫面顯示玩家、怪物、地圖、生命、彈藥、大招能量、強化層數與比賽時間。
4. 玩家可以使用 WASD 移動、滑鼠瞄準、滑鼠左鍵普攻、滑鼠右鍵大招與 Space 使用配件。

## 執行自動測試

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s pvpve_escape\tests -p "test_*.py" -v
```

預期結果：純規則測試全部通過，至少涵蓋以下行為：

- 強化層數 0～10 與每層 3% 公式。
- 有效傷害轉換為大招能量，能量上限 100，使用後歸零。
- 彈藥低於容量時自動補回，補彈間隔使用角色設定值。
- 怪物最後一擊歸屬與重生計時。
- 死亡時清除強化、大招能量與撤離進度，5 秒後重生。
- 配件冷卻與可使用狀態。
- 撤離區啟用時間、個別進度、多人成員同區持續累積與離場個別歸零。
- 先完成 10 秒撤離者獲勝、同幀裁決與時間到無人勝利。

## 手動驗證情境

### 情境 1：角色與配件選擇

1. 啟動遊戲。
2. 依序選擇六種角色與三種配件各一次。
3. 確認每次開始時人類玩家使用選定角色，五名假玩家使用其餘角色；可由地圖上的角色形狀、頭上名稱與右下玩家／角色名冊辨識。
4. 確認配件開局可用，使用後顯示冷卻倒數。

### 情境 2：移動、鏡頭與地圖邊界

1. 使用 WASD 向四個方向移動。
2. 走到世界邊界，確認玩家不會移出地圖。
3. 移動到遠離出生點的位置，確認鏡頭跟隨玩家且不顯示世界外區域。

### 情境 3：六種專屬戰鬥

1. 在結算畫面按 `R` 回到角色／配件選擇頁，分別選擇六種角色。
2. 確認每種角色的普攻形態與顏色不同；狙擊者按住左鍵蓄力，吸能者按住左鍵維持光束，其餘角色按左鍵即可施放。
3. 確認玩家與小怪頭上都有血條及目前／最大生命值，依數值確認每種角色的被動在對應條件下生效。
4. 對怪物造成傷害直到大招充滿，使用大招並確認能量歸零及大招特效出現。

首版角色效果對照：

| 角色 | 普攻 | 被動 | 大招 |
|---|---|---|---|
| 破陣者 | 60° 五彈丸扇形散射 | 180 內傷害 +20% | 半徑 180 爆發與擊退 |
| 狙擊者 | 0.6 秒蓄力直線射擊 | 超過 450 距離傷害 +20% | 射程 1000 穿透線 |
| 守衛者 | 前方弧形盾牌衝擊 | 最大生命值 +20% | 4 秒減傷 70% |
| 追獵者 | 往返回旋飛刃 | 移動速度 +15% | 突進、免傷與路徑傷害 |
| 控場者 | 重力地雷 | 控制時間 +50% | 半徑 170 重力牢籠 |
| 吸能者 | 近距離持續吸能光束 | 對怪物能量 +25% | 半徑 200 傷害與吸血 |

### 情境 4：怪物成長與死亡重置

1. 攻擊並擊殺怪物，確認最後擊殺者取得一層強化。
2. 重複擊殺直到 10 層，確認不會超過上限。
3. 讓玩家死亡，確認強化與大招能量清除。
4. 等待 5 秒，確認玩家在外圍安全位置重生且可重新操作。

### 情境 5：撤離區單人勝利

1. 等待比賽進入最後 30 秒。
2. 進入中央撤離區並持續停留 10 秒。
3. 確認玩家立即獲勝，且比賽停止更新。

### 情境 6：多人同區與個別進度

1. 按 F1 開啟開發者模式。
2. 使用數字鍵 1～5 選取假玩家。
3. 按 `M` 將假玩家放入中央撤離區。
4. 讓人類玩家與假玩家同時停留，確認兩人的撤離進度都持續增加，不會暫停。
5. 讓人類玩家離開，確認只有人類玩家的進度歸零，假玩家進度保持不變。
6. 讓人類玩家重新進入並先完成 10 秒，確認人類玩家獲勝。

### 情境 7：時間到無人勝利

1. 不讓任何玩家完成 10 秒撤離。
2. 等待比賽達到 4 分鐘。
3. 確認顯示無人勝利，且可以重新開始或離開。
