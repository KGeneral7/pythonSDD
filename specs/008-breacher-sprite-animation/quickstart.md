# 快速開始與驗證：破陣者 Q 版像素角色與八方向動畫

## 前置條件

- Windows 桌面環境。
- Python 3.11 或更新版本。
- 專案虛擬環境已安裝 `pvpve_escape/requirements.txt` 中的依賴。
- `pvpve_escape/assets/characters/breacher/` 已放入 8 張待機、32 張移動與 32 張攻擊圖片，共 72 張。

## 素材快速檢查

在專案根目錄執行 PowerShell：

```powershell
$assetRoot = 'pvpve_escape/assets/characters/breacher'
(Get-ChildItem -LiteralPath $assetRoot -Recurse -File -Filter '*.png').Count
```

預期結果為 `72`。每張圖片必須是 1024×1024、四個角落為透明像素、非透明角色像素未貼住或超出邊界，同一方向動畫幀的非透明內容中心偏移不超過 16 個來源像素，並通過逐張人工檢查。若確認是角色創意或像素內容問題，必須重新生成；若只是可明確判定的生成器背景、透明 alpha、畫布尺寸或置中格式問題，可用不改角色內容的確定性整理流程處理後再驗證。

## 自動測試

在專案根目錄執行：

```text
python -m unittest discover -s pvpve_escape/tests -p "test_*.py"
```

預期結果：新增的方向、幀選擇、動畫狀態、圖片載入與 fallback 測試通過，既有角色、怪物、地圖、碰撞與戰鬥測試也全部通過。

## 手動端到端驗證

啟動遊戲：

```text
python -m pvpve_escape
```

依序執行：

1. 在選角畫面選擇破陣者，確認角色卡片顯示 Q 版像素待機外觀。
2. 進入對局，使用滑鼠將瞄準方向切換到右、右下、下、左下、左、左上、上、右上；上、左上、右上應顯示背面方向，不得回到朝下的正面。
3. 在每個方向使用 WASD 移動，確認四格移動動畫循環播放且角色不裁切、不漂移。
4. 移動中按左鍵普攻，確認四格攻擊動畫優先於移動動畫。
5. 分別使用 Space 戰術技能與右鍵終極技能，確認兩者也播放同一套四格攻擊動畫。
6. 確認槍與盾保持分離、各自接觸手部，俯視角下不會被程式旋轉或拼接變形。
7. 確認破陣者每個方向與動畫幀的角色外框統一落在 50×50 顯示畫布內，存活角色下方沒有常駐底圈或玩家外框。
8. 測試死亡與重生，確認死亡標記保留，重生後回到待機或移動外觀。
9. 選擇其他角色並觀察怪物，確認它們仍使用原本外觀與行為。
10. 確認玩家列表的破陣者圖示沒有遮住名稱與狀態文字，且文字完整位於面板內。
11. 連續遊玩 10 秒，確認平均每秒至少 60 個畫面更新、任一單幀間隔不超過 100 毫秒，且沒有閃爍、方向錯置、裁切或空白角色。

## Fallback 驗證

使用自動測試模擬任一圖片缺失、讀取失敗或透明度不合格，重新繪製選角與對局畫面。預期破陣者改用既有幾何圖形，遊戲不中斷，其他角色與怪物不受影響。

## 通過條件

- 72 張素材檢查通過。
- 全部自動測試通過。
- 八方向、移動、普攻、戰術技能、終極技能、死亡／重生與 fallback 手動情境通過。
- 10 秒連續遊玩平均每秒至少 60 個畫面更新，任一單幀間隔不超過 100 毫秒，且沒有閃爍、空白角色、方向錯置或裁切。
