**目的**：確認本功能規格完整描述瞄準操作、投射物一致性、角色與怪物平衡，以及既有 PvPvE 規則的相容性。

**功能**：[spec.md](../spec.md)

**檢查說明**：本清單是由需求審查者維護的規格品質檢查結果。只有在確認需求品質條件已滿足時才標記 `[x]`；標記完成不代表程式已實作完成。

## 使用者價值與範圍

- [x] CHK001 每個使用者故事都描述明確角色、目標與可觀察價值，且依核心瞄準、可讀性、碰撞可靠性、平衡驗收排序。
- [x] CHK002 每個使用者故事都包含可獨立執行的測試方式，不需要先完成其他非必要故事才能判斷價值。
- [x] CHK003 規格明確區分本次新增的瞄準、飛行物速度、角色數值與怪物數值，並列出不變的既有 PvPvE 規則。
- [x] CHK004 規格明確說明《荒野亂鬥》是定位與體驗參考，不要求複製外部角色資產、名稱、數值或素材。

## 行為完整性與邊界

- [x] CHK005 規格定義按住預覽、放開施放、快速點按、資源不足、死亡及視窗失去焦點時的完整行為。
- [x] CHK006 規格定義吸能者持續引導作為一般放開施放模型的明確例外，並說明停止條件。
- [x] CHK007 六種角色的瞄準形狀、射程、落點或引導方式均有獨立驗收情境，沒有以單一泛化描述取代角色差異。
- [x] CHK008 規格涵蓋地圖邊界、快速投射物跨越目標、多顆投射物、目標死亡、護盾、免傷與控制免疫等邊界情況。
- [x] CHK009 規格明確要求圖像位置、連續路徑、碰撞結果與命中提示一致，能直接驗收狙擊顯示命中但未造成傷害的問題。
- [x] CHK010 規格明確要求控場地雷落地前不產生傷害或控制，並定義落點受地圖邊界限制時的行為。

## 數值與可驗證性

- [x] CHK011 六種角色均列出初始生命、普攻火力、射程與飛行速度，且清楚標示近戰或持續引導不適用飛行速度。
- [x] CHK012 角色表中的被動條件、大招基準、散射顆數、引導間隔與有效生命解讀足以支持後續實作與驗收。
- [x] CHK013 近戰怪物的生命、速度、接觸傷害、攻擊間隔、碰撞半徑、每區數量與重生時間均有明確數值。
- [x] CHK014 成功標準包含瞄準操作、命中一致性、飛行速度、角色擊殺節奏、怪物數值與既有流程回歸的可衡量結果。
- [x] CHK015 成功標準中的重複測試次數、目標狀態與例外條件足以避免把護盾或免傷誤判為碰撞錯誤。

- [x] CHK016 功能需求均使用單一明確行為描述，沒有以模糊的「適當」「正常」或未定義的外部服務作為完成條件。

- [x] CHK018 關鍵實體涵蓋瞄準預覽、戰鬥動作、飛行物、角色平衡資料、近戰怪物與命中結果，並說明各自責任。
