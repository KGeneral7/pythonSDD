# 快速開始與驗證指南：瞄準線、飛行物速度與角色戰鬥平衡

## 前置條件

- Windows PowerShell。
- Python 3.11 或更新版本；專案虛擬環境位於 `.venv`。
- 專案根目錄為 `C:\Users\Yun-Tse Kao\Desktop\pythonSDD`。
- Pygame 由 `pvpve_escape/requirements.txt` 安裝於專案虛擬環境。

## 安裝依賴

在專案根目錄執行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r pvpve_escape\requirements.txt
```

預期結果：Pygame 安裝或確認為目前虛擬環境版本，不修改全域 Python。

## 自動驗證

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s pvpve_escape\tests -p "test_*.py" -v

預期結果：既有回歸測試與本功能新增測試全部通過，涵蓋：

- 非引導技能按住／放開／快速點按、失焦清除，以及吸能者普攻持續引導／放開停止。
- 破陣者五顆散射彈、狙擊子彈、追獵飛刃與控場地雷的速度與連續碰撞。
- 顯示命中、有效傷害、護盾、免傷與無效結果的一致性。
- 六角色生命、火力、射程、速度、被動與大招基準。
- 近戰怪物生命 85、速度 95、接觸傷害 12、攻擊間隔 0.8 秒與 6 秒重生。
- 原有彈藥、能量、強化、死亡重生、中央撤離與重新開始流程。

```

## 手動驗證情境

### 情境 1：六種角色的瞄準預覽

1. 依序重新開始並選擇破陣者、狙擊者、守衛者、追獵者、控場者、吸能者。
2. 對每個角色按住滑鼠左鍵並移動滑鼠。
3. 確認預覽分別呈現扇形、直線、近戰弧形、去回路徑、落點／控制圈與光束線。
4. 將滑鼠指向地圖邊緣，確認預覽端點不顯示世界外區域。
5. 確認非引導技能按住期間沒有扣彈藥、傷害或冷卻；吸能者普攻則只在持續引導期間依 0.15 秒間隔作用。

### 情境 2：放開施放與吸能者例外

1. 使用破陣者按住左鍵約 1 秒後放開，確認只出現一輪五顆散射彈；持續按住不得連續自動發射。
2. 快速點按非吸能者普攻或任一角色的大招／配件一次，確認仍施放一次；吸能者普攻快速點按不建立引導。
3. 使用狙擊者按住左鍵觀察蓄力與瞄準線，放開後確認只產生一顆子彈。
4. 使用右鍵與 `Space` 重複測試大招／配件：所有角色按住只顯示預覽，放開只施放一次；資源不足或冷卻中顯示無效色預覽且不產生效果。控場配件放開時立即在預覽落點建立控制區，不播放飛行物。
5. 使用吸能者按住左鍵，確認光束持續作用；放開、死亡或切換焦點後確認光束立即停止。

### 情境 3：飛行速度與狙擊命中一致性

1. 讓目標位於狙擊者直線上、另一目標偏離直線；按住後放開左鍵。
2. 確認子彈以可見速度向前移動，而非施放瞬間跳到目標。
3. 確認直線上的無護盾目標在圖像抵達時扣除生命；偏離目標不受傷。
4. 對有護盾或免傷的目標射擊，確認命中位置固定、生命／護盾結果與文字一致，不顯示虛假的有效傷害。
5. 以追獵者飛刃與控場者地雷重複測試：目標在一個畫面更新間隔內被路徑跨過時不得漏判。

### 情境 4：散射與地雷落地

1. 使用破陣者在怪物附近施放，確認五顆彈道各自可見，命中數量依實際路徑決定。
2. 使用控場者把地雷投向怪物，確認地雷飛行期間不造成傷害／減速。
3. 地雷到達落點後讓怪物進入範圍，確認才觸發傷害與控制，並與落點圓形提示重合。

### 情境 5：角色與怪物平衡

1. 在選擇畫面確認六種角色卡片／HUD 顯示的生命、火力、射程與飛行速度與規格表一致。
2. 建立固定 TTK 夾具：目標 120 生命、碰撞半徑 40、無護盾／減傷／免疫，玩家無強化；狙擊者距離 500、破陣者／守衛者距離 50、追獵者／吸能者距離 100，並啟用適用的距離被動且每次都符合完整命中條件。確認狙擊者 2～3 次、破陣者／守衛者／追獵者 3～5 次（破陣者五顆全中，追獵者每次須去程與回程各命中一次），吸能者（每次 1.2 秒、8 次命中）約 3 次；控場者不納入此比較。
3. 讓守衛者承受傷害，確認未強化有效生命為 138；讓狙擊者遠距離、破陣者近距離攻擊，確認被動增傷仍生效。
4. 觀察近戰怪物，確認其生命為 85、移動速度較原版本提高、接觸攻擊為 12 且攻擊間隔為 0.8 秒。
5. 擊殺怪物並等待 6 秒，確認原生成區重生；最多每區同時有 3 隻。

### 情境 6：既有 PvPvE 回歸

1. 擊殺怪物取得強化，確認最多 10 層；讓玩家死亡，確認強化、大招能量、撤離進度與正在進行的預覽清除。
2. 等待 5 秒，確認玩家以角色基準生命與完整彈匣重生。
3. 等待最後 30 秒，進入中央撤離區；確認單人持續 10 秒獲勝。
4. 用 F1 開啟開發者模式，數字鍵選假玩家，按 `M` 放入撤離區；確認兩名以上玩家同區時各自持續累積，離開者只有自己的進度歸零。
5. 不完成撤離直到 4 分鐘，確認顯示無人勝利；按 `R` 回到角色／配件選擇頁。
