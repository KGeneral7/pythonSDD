# 任務：瞄準線、飛行物速度與角色戰鬥平衡

**輸入**：`specs/002-aim-balance-projectiles/` 下的 `spec.md`、`plan.md`、`research.md`、`data-model.md`、`contracts/aim-guide-ui.md` 與 `quickstart.md`。

**前置條件**：完成 `plan.md`、`data-model.md` 與使用者介面契約；專案使用 Python 3.11.5、Pygame 2.6.1 與標準函式庫 `unittest`，不新增第三方依賴。

**測試策略**：每個使用者故事的測試任務先於該故事的實作任務；純資料／規則使用 `unittest`，畫面行為使用無頭 Pygame 表面與 `quickstart.md` 的手動情境驗證。

**執行原則**：每個任務完成後執行最小對應測試或啟動檢查，保留可執行版本，再進入下一個任務；不得修改 `day1/` 與 `day2/`。

## 任務格式

- `[P]`：可與同階段其他任務平行執行，且不會修改同一檔案或依賴未完成的前置任務。
- `[US1]`～`[US4]`：對應 `spec.md` 的四個使用者故事；設定／基礎建設／整理任務不加故事標籤。
- 每一項任務都包含連續任務編號、必要標籤與明確檔案路徑。

**檢查點**：`.venv` 可使用 Python 3.11.5 與 Pygame，初始基線的 35 項測試維持通過，且新功能尚未改變工作樹中的既有程式。

## 階段 3：使用者故事 1——以瞄準線準備並施放技能（優先級：P1）🎯 MVP

**目標**：玩家按住非引導技能時只看見預覽，放開時只施放一次；吸能者普攻維持按住引導，快速點按、資源不足、死亡與失焦都不會產生錯誤動作。
