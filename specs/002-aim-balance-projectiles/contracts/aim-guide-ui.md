# 使用者介面契約：瞄準預覽與施放

**功能**：`002-aim-balance-projectiles`

**契約對象**：桌面本機 Pygame 人類玩家介面。此文件描述玩家輸入與可觀察畫面行為，不提供網路 API 或外部資料交換格式。

## 輸入契約

| 操作 | 按住期間 | 放開時 | 例外／限制 |
|---|---|---|---|
| 滑鼠左鍵 | 非吸能者顯示普攻預覽；狙擊者累積蓄力；吸能者普攻持續引導 | 非吸能者施放一次；狙擊者依蓄力施放；吸能者普攻停止引導 | 彈藥不足時不施放；只有吸能者普攻是持續按住例外 |
| 滑鼠右鍵 | 顯示目前大招的方向、範圍或突進預覽 | 能量滿時施放一次並將能量歸零 | 能量不足時不產生效果 |
| `Space` | 顯示目前戰術配件預覽 | 冷卻完成時施放一次並啟動冷卻 | 冷卻中不產生效果 |
| 滑鼠移動 | 更新世界瞄準方向及預覽端點 | 施放使用放開當下方向 | 不自動鎖定目標 |
| WASD | 移動玩家；預覽跟隨玩家起點 | 不改變施放次數 | 玩家不可超出地圖 |
| 視窗失去焦點 | 清除所有按住／預覽狀態 | 不補發動作 | 回到視窗後必須重新按下 |

### 邊緣語意

- `pressed` 是按下邊緣、`held` 是當前按住狀態、`released` 是放開邊緣；同一個按住週期最多一個 `released`。
- 快速按下／放開必須仍能施放非引導技能（非吸能者普攻、所有角色大招或配件）一次；吸能者僅普攻必須以按住方式建立可觀察的引導，快速點按不建立引導。
- 非引導技能預覽期間不消耗彈藥、能量、冷卻或生命，不建立傷害事件；吸能者普攻依持續引導規則作用。
- 玩家死亡、重生、重新開始或比賽結束時預覽消失；不允許在新生命週期自動繼續施放。

## 預覽輸出契約

### 普攻

| 角色 | 預覽內容 | 施放後對應效果 |
|---|---|---|
| 破陣者 | 200 距離、60 度扇形、5 條散射方向 | 5 顆獨立、900 速度的散射彈 |
| 狙擊者 | 1000 距離直線、端點、方向 | 1400 速度子彈，沿可見路徑碰撞 |
| 守衛者 | 125 距離、100 度近戰弧形 | 即時弧形傷害，不顯示飛行子彈 |
| 追獵者 | 最長 340 的去程／回程路徑 | 520 速度飛刃，去回路徑各自判定 |
| 控場者 | 最長 460 的投射方向、落點與半徑 100 圈 | 650 速度地雷，落地後才傷害／控制 |
| 吸能者 | 最長 280 的持續光束線 | 按住期間每 0.15 秒作用，放開停止 |

### 大招與配件

- 破陣者／吸能者：顯示以施放位置為中心的爆發圈。
- 狙擊者：顯示 1100 射程的穿透直線與端點。
- 守衛者：顯示自身 4 秒減傷的護盾圈。
- 追獵者：顯示 360 突進路徑及終點。
- 控場者：顯示 190 半徑重力牢籠；控場配件顯示受邊界限制的目標落點與半徑 100 控制圈，放開時立即在該落點建立非飛行控制區。
- 衝刺配件：顯示位移方向與落點；護盾配件：顯示自身防禦圈。
- 同時存在多個可預覽按鍵時，畫面優先顯示大招、戰術配件、普攻。

## 命中與回饋契約

- 可飛行物的畫面位置與碰撞使用同一個本幀前後位置線段；高速飛行物跨過目標時仍必須判定。
- 只有實際碰撞及效果結果成立時才顯示「命中」；護盾、免傷或無效結果必須顯示相符狀態。
- 狙擊子彈命中後，命中標記固定在實際碰撞位置，不跟隨目標移動，也不重複對同一目標造成後續傷害。
- 控場地雷抵達落點前不得顯示或套用控制結果；落點受地圖邊界限制時，圖形與效果必須使用同一落點。
- 預覽不是自動瞄準，不保證目標會停留在路徑內；施放後依實際位置與目標狀態裁決。

## 資源與失敗回饋

- 普攻彈藥、狙擊蓄力、大招能量與配件冷卻狀態由 HUD 顯示；無法施放時不扣除資源。
- 玩家可看到預覽但資源不足或冷卻未完成時，預覽固定以無效色弱化呈現；放開時不產生效果、不扣除資源，也不得顯示有效命中。
- 既有角色血條、怪物血條、護盾／免傷／控制狀態與命中文字仍是結果回饋的一部分。

## 驗收契約

1. 六種角色的普攻按住時均有不同形狀，且方向、端點與範圍隨瞄準更新。
2. 非引導技能按住後放開只施放一次；快速點按也能施放；吸能者僅普攻按住持續、放開停止，快速點按不建立引導。
3. 破陣散射彈、狙擊子彈、追獵飛刃與控場地雷均能觀察到飛行，且速度與碰撞結果一致。
4. 顯示狙擊命中時，無護盾／免傷的目標生命必須下降；有阻擋狀態時必須顯示阻擋而非有效傷害。
5. 新介面不改變死亡重置、怪物強化與中央撤離的既有結果。
